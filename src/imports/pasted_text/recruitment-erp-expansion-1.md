## MASTER PROMPT — COMPLETE RECRUITMENT ERP SYSTEM EXPANSION

Expand the existing recruitment ERP design into a **complete, modern, scalable recruitment business management platform**.

Do **not** redesign the existing system from scratch. Preserve the current branding, colors, typography, navigation patterns, spacing, cards, buttons, tables, icons, and overall design language. Extend the existing design system so all new features feel like they were part of the original ERP from day one.

The objective is to create one integrated system connecting:

**Candidates + Recruitment + Agents + Jobs + Employers + Documents + Passport Custody + Finance + Payments + AI + Tasks + Communications + Reports + Users + Security**

# 34. DESIGN THE SYSTEM AS ONE CONNECTED ERP

The most important requirement is that these modules must **connect to each other**.

For example:

A candidate should connect to:

**Candidate → Agent → Job → Employer → Documents → Passport → Medical → CV → Payments → Expenses → Tasks → Communications → Placement → Profit**

An agent should connect to:

**Agent → Candidates → Jobs → Passports → Tasks → Payments → Placements → Performance**

An employer should connect to:

**Employer → Vacancies → Candidates → Contracts → Invoices → Payments → Revenue**

Management should connect everything through:

**Dashboard → Reports → Analytics → Growth → Revenue → Expenses → Profit**

Make the product feel like a **single intelligent recruitment ERP**, not separate disconnected applications.

Prioritize a clean, professional, enterprise-grade experience with strong information hierarchy, fast workflows, clear permissions, powerful search, and actionable dashboards.
